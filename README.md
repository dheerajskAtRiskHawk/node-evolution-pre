## Quick start

1. Clone or open this repo.
2. Use **Node.js 20+** (22 or 24 recommended).
3. Run the code for each video from the repo root, e.g.:

   ```bash
   node video-01/code/version-check.js
   node video-01/code/changelog-tags.js
   node video-01/code/bridge-module.js
   ```

   For Video 2 (full project):

   ```bash
   cd video-02 && npm run demo
   ```

   For Video 3 (permissions):

   ```bash
   cd video-03 && npm run demo
   ```

   For Video 4 (HTTP & networking):

   ```bash
   cd video-04 && npm run demo
   ```

See each video’s `README.md` for the full script and run instructions.

## Audience

Beginners new to Node.js who want a simple, concise path from Node 20 to 24 without deep engine details. Concepts are explained in plain language; code and scripts are heavily commented.
